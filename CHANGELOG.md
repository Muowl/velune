# Changelog

## 0.2.0 — 2026-10-28

- Rebalanced the dark palette with lighter plum backgrounds, softer text and pastel syntax.
- Replaced crimson primary buttons and error-colored hover with dedicated muted control colors.
- Softened badges, remote status, cursor and focus accents while keeping keyboard focus visible.
- Harmonized ANSI and diagnostic colors; preserved language token classifications and the original umbrella artwork.
- Added control-state contrast checks, restrained-fill regression checks and a generated UI preview.

## 0.1.3 — 2026-10-23

- Adopted the MIT license.
- Added Rust and Java grammar validation, bringing the suite to 12 languages.
- Fixed Java type references, generics, arrays, annotations, lambdas, wildcards and Javadoc colors.
- Refined Rust attributes, characters and format-string captures.
- Added rust-analyzer semantic rules for booleans, lifetimes, escapes, attributes and mutable variables.
- Aligned Java constructor and documentation colors with syntax highlighting.

## 0.1.2 — 2026-10-23

- Added the lavender umbrella icon with a crimson handle.
- Added SVG assets, a 256px extension icon and reproducible 1024px PNG exports.

## 0.1.1 — 2026-10-23

- Added C# and C++ grammar validation and semantic contracts for C#, C/C++ and clangd.
- Fixed C# delegate, escape and XML documentation colors.
- Refined C++ references, pointers, attributes, casts and lambda return types.
- Added clangd semantic rules for concepts, modifiers, constructors and destructors.
- Added a generated syntax preview checked by CI.

## 0.1.0 — 2026-10-23

- Initial Velune Dark theme for VS Code.
- Added workbench colors, TextMate highlighting, semantic token colors and ANSI terminal colors.
- Established a shared palette and color roles for theme generation.
- Kept code and comments free of automatic bold or italic styling.
- Adjusted selection, search and Git diff backgrounds to preserve comment readability.
- Added fixtures and automated checks for eight grammars, including Markdown.
